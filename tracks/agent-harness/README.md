# Трек: агентные харнессы

Инженерия систем вокруг языковой модели. Не «как устроена модель» — этому
посвящён трек [`ml-interviews`](../ml-interviews/), — а как построить вокруг неё
работающий цикл: инструменты, контекст, изоляция, остановка.

Тема выбивается из подготовки к интервью намеренно. Харнессы в 2026 году —
быстро меняющаяся область, и лекция про конкретный инструмент устареет за
полгода. Поэтому темы здесь привязаны к **инженерным задачам**, которые
никуда не денутся: контекст конечен, модель ошибается, действия необратимы.
Конкретные харнессы служат источником примеров, а не предметом изучения.

## Источники примеров

Разбор опирается на шесть открытых харнессов, у которых, несмотря на разные
языки и архитектуры, повторяется один и тот же набор подсистем:

| Харнесс | Чем интересен |
|---|---|
| [OpenHands SDK](https://github.com/OpenHands/software-agent-sdk) | самый проработанный Python-SDK: сжатие контекста, инварианты истории, ACP |
| [OpenHands / Agent Canvas](https://github.com/OpenHands) | оболочка поверх нескольких агентов |
| [DeepSeek Harness](https://deepseek.com) | архитектура «всё — плагин» |
| [OpenCode](https://opencode.ai) | плагины и инструменты пользователя |
| [Hermes Agent](https://hermes-agent.nousresearch.com/) | плагины, инструменты, память |
| OpenClaude | разрешения и песочница в терминальном агенте |

## Темы

| Тема | Про что |
|---|---|
| [`agent-loop/`](agent-loop/) | цикл «модель → инструмент → наблюдение», состояние, остановка, зацикливание |

Планируются: управление контекстом и его инварианты, инструменты и function
calling, песочница и разрешения.

## Формат

Тот же, что в треке `ml-interviews`: развёрнутое объяснение с матчастью,
запускаемый код и иллюстрации, посчитанные на данных.

```
<тема-слаг>/
  lesson.md  generate_visuals.py  lecture_llm_images.json  assets/  [notebook.ipynb]
```

Философская сторона той же темы — в эссе [`essays/spiral/`](../../essays/spiral/new_spiral.md).
